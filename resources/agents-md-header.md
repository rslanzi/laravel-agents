# AGENTS.md

Guidelines for AI coding agents (Claude Code, Codex, Cursor, Junie, Copilot) working on this Laravel application. They are shipped by the `rslanzi/laravel-agents` package, extend the Laravel Boost guidelines and win over generic advice when the two differ. Project-specific rules (bounded contexts list, domain glossary, extra arch rules) belong in an extra file under `.ai/guidelines/`.
